# Security policy

This policy covers every public repository in the tissue-systems organization
that doesn't have a SECURITY.md of its own.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Either email
[security@tissue.systems](mailto:security@tissue.systems), or use the
"Report a vulnerability" button on the repository's Security tab, which opens a
private advisory only we can see.

Tell us what you found and how to reproduce it. A small program or a test case
that shows the problem is the most useful thing you can send.

We'll reply to say we've got the report, keep you posted while we work on a
fix, and credit you in the release notes unless you'd rather we didn't. Please
give us a reasonable amount of time to ship the fix before you publish.

## Supported versions

Fixes go into the latest release only, unless a repository says otherwise.

## Tissue Cloud itself

A problem with the hosted service (tissue.systems, the API, the dashboard,
Cells running on tissue.dev) goes to the same address. Please don't test
against other people's Cells or accounts.
